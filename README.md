20‑Day React Mastery Series

A step‑by‑step journey from absolute beginner to a confident React developer.  
Each day covers one core concept, a practical assignment, and a complete solution.

---

##  Repository Structure
.
├── day-01/ # Components & JSX
├── day-02/ # Props & default props
├── day-03/ # useState hook
├── ...
├── day-20/ # Final mini‑project
├── .gitignore
└── README.md


Each `day-XX/` folder is a **standalone React project** (bootstrapped with Vite, Create React App, or your preferred tool).  
This lets you experiment freely without affecting previous days.

---

##  Prerequisites

- Basic knowledge of **HTML, CSS, and JavaScript** (ES6+).
- **Node.js** (v16 or later) and **npm** / **yarn** installed.
- A code editor (VS Code recommended).

##  How to Use This Repository

1. **Clone** this repository:
   ```bash
   git clone <your-repo-url>
   cd <repo-name>

2. Navigate into any day’s folder, for example:
	cd day-01

3. Install dependencies:
	npm install
	# or
	yarn install

4. Start the development server:
	npm start
	# or
	yarn start

5. Open http://localhost:3000 (or the port shown) to see your work.
